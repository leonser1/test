# Убирающиеся ножки для «Колибри»

Четыре ножки на серединах лучей. Резинка держит их сложенными под лучом. Одна серво в центре наматывает нити на катушку и откидывает все ножки до упора 95°.

## Крепёж и расходники

- Ось шарнира: 4 × винт M2×16 с контргайкой (или спица Ø2 мм).
- Колодка на луч: 2 хомута 3.6 мм на колодку, либо винт M3 сквозь луч.
- Серво SG90 / MG90S, 2 самореза M2 в крепление, качалка крепится к катушке саморезами 1.5–2 мм.
- Крепление серво: 4 × M3 на шаблон стека 30.5 × 30.5 снизу нижней плиты.
- Нить: кевлар или плетёнка 0.3 мм, 4 отрезка по ~15 см.
- Резинка: маленькое кольцо Ø10–15 мм (резинка для брекетов / O-ring), 4 шт.

## Сборка

1. Вставить ножку между ушами колодки, продеть ось M2. Ножка должна качаться свободно, без люфта.
2. Надеть пятку из TPU на конец ножки (на каплю клея).
3. Резинку накинуть на штырь, провести под ножкой через проточку и накинуть на второй штырь. Ножка должна сама прижиматься к лучу.
4. Колодку надеть на луч снизу, ось шарнира ближе к центру, штыри ближе к мотору. Затянуть хомутами.
5. Нить привязать к отверстию в рычажке, провести через ушко колодки к центру.
6. На катушке 2 уровня: нижний для пары лучей по одной диагонали, верхний для другой. Нити одной пары наматываются навстречу друг другу, в разные половины барабана.
7. Серво в 0°, ножки сложены. Натянуть нити без слабины, привязать в отверстия фланцев.
8. Выставить конечную точку серво так, чтобы все 4 ножки дошли до упора (≈107° поворота катушки). Серво не должно упираться: лишний ход греет его и тянет ток.

## Расчётные величины

| Параметр | Значение |
|---|---|
| Ход ножки | 0° → 95° (упор зубом ступицы в колодку) |
| Ход нити | 14.9 мм |
| Поворот катушки Ø16 | ≈107° |
| Кончик пятки ниже луча | ≈67 мм |
| Серво с катушкой ниже рамы | ≈40 мм, запас клиренса ≈27 мм |

## Под свою раму

Все размеры задаются в начале `generate.py`: ширина луча `ARM_W`, длина ножки `LEG_LEN`, шаблон стека `STACK`, радиус катушки `SPOOL_R` и т.д.

```bash
pip install manifold3d numpy trimesh
python3 generate.py --check   # проверка столкновений по всему ходу и расчёт нити
python3 generate.py           # пересобрать stl/
python3 render_preview.py     # обновить preview.png (нужен matplotlib)
```

После изменения `PIVOT_DEPTH`, `TOOTH_R` или `TOOTH_ANGLE` запустите `--check`: строка «первое касание при раскрытии» должна показывать 95°.

## Безопасность

- Если серво обесточится, резинки сложат ножки и дрон сядет на брюхо.
- Моторы на столе проверять только без пропеллеров.
- Ход серво и его конечные точки проверять до установки нитей, чтобы серво не порвало их и не сломало рычажки.
