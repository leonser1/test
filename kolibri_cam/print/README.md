# Печать на Creality Ender-3 V3 SE (PETG)

| Файл | Что это |
|---|---|
| `Kolibri_cam_tilt_Ender3V3SE_PETG.gcode` | готовый G-code: на флешку → «Печать» |
| `Kolibri_cam_tilt_Ender3V3SE_PETG.3mf` | проект: обе детали расставлены по центру стола (открыть в Creality Print / PrusaSlicer / Orca) |
| `ender3v3se_PETG.ini` | профиль PrusaSlicer, которым резалось |
| `gcode_preview.png` | первый слой и траектории |

**Настройки:**
- сопло 0.4, PETG 1.75;
- температура 240 °C на первом слое, дальше 235 °C; стол 75 °C;
- слой 0.2, 4 периметра, 5 верхних и 4 нижних слоя, заполнение 40 % гироид;
- скорость 25–90 мм/с, ускорения до 2500;
- откат 0.8 мм / 40 мм/с, подъём по Z 0.2;
- юбка, кайма 4 мм, без поддержек.

Время ≈ **1 ч 43 мин**, PETG ≈ **19 г** (6.2 м).

**Перед печатью:**
1. Сделать автовыравнивание стола в меню принтера. Сетку подхватит `M420 S1` в начале G-code.
2. Стол чистый, без жира. Для PETG на PEI клей не нужен, на гладком стекле нужен клей-карандаш.
3. Если печатаете PLA вместо PETG: перерезать с 210 °C / 60 °C — либо из `ender3v3se_PETG.ini`, либо в Creality Print из 3MF.

Пересобрать: `prusa-slicer --export-gcode --load ender3v3se_PETG.ini --center 110,110 --merge <2 STL> -o <файл>.gcode`
