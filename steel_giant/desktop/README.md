# Стальной гигант: живой виджет для рабочего стола Windows

Гигант прилетает на экран, садится на панель задач, ходит, машет рукой,
поворачивается к курсору, взлетает, кружит поверх окон и иногда улетает
за край экрана, а потом возвращается с другой стороны.

Иногда налетает рой FPV-дронов. Гигант сбивает их лазером из глаз,
плазменной пушкой, которая выдвигается из руки, и ракетами из пусковой
установки на плече. Дроны пытаются протаранить его. Последний дрон всегда прорывается:
гигант разлетается на детали, они лежат и подёргиваются, глаза гаснут,
потом детали по очереди прыгают на свои места (ступни, голени, бёдра,
талия, грудь, руки, голова), глаза загораются. Собравшись, он поворачивается
лицом к экрану, поднимает кулак и смотрит вперёд, потом снова живёт
обычной жизнью до следующего налёта.

Окно прозрачное, клики проходят сквозь него, работать ничто не мешает.
Если навести курсор на гиганта и кликнуть, он помашет и взлетит.

## Запуск

1. Установите Node.js LTS: https://nodejs.org
2. Распакуйте папку и дважды кликните `start.bat`.
   При первом запуске скачается Electron (около 100 МБ, 1–2 минуты).

## Управление

Иконка гиганта в трее (у часов), правый клик:
- **Позвать гиганта** — прилетит заново;
- **Бой с дронами** — налёт прямо сейчас;
- **Пауза**, **Размер** (маленький / средний / большой);
- **Запускать вместе с Windows** (только в собранном .exe);
- **Выход**.

Настройки сохраняются между запусками.

## Сделать один .exe без Node.js

Дважды кликните `build-exe.bat`. Готовый `dist/SteelGiant.exe` можно
копировать на любой компьютер с Windows и запускать без установки.

## Файлы

- `giant.html` — сам гигант: рисунок, анимация, «поведение»;
- `main.js` — прозрачное окно поверх всех окон и меню в трее;
- `preload.js` — связь между ними.
