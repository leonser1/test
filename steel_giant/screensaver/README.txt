Огненный дождь — заставка Windows
==================================

Падающие горящие точки, как угольки: медленно падают, покачиваются
на ветру и остывают от бело-жёлтого к тёмно-красному.

Установка
---------
1. Распакуйте архив.
2. Правый клик по файлу Embers.scr -> «Установить».
   Откроется окно «Параметры экранной заставки» — заставка уже выбрана.
   Нажмите «Применить».

   Если пункта «Установить» нет: скопируйте Embers.scr в папку
   C:\Windows\System32, потом откройте Параметры -> Персонализация ->
   Экран блокировки -> Заставка и выберите «Embers».

3. Кнопка «Параметры» в окне заставки: густота, скорость, ветер.
   Кнопка «Просмотр» — посмотреть сразу.

Если Windows покажет «Windows защитила ваш компьютер» (файл без
цифровой подписи): «Подробнее» -> «Выполнить в любом случае».

Работает на Windows 7/10/11 (нужен .NET Framework 4, он уже есть в системе).
Заставка закрывается от движения мыши, клика или любой клавиши.
Показывается на всех мониторах.

Исходный код: Embers.cs
